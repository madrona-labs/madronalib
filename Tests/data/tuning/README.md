# Tuning test fixtures

`*.scl`, `*.kbm` and `bad/*` are copied unchanged from the test data of
[surge-synthesizer/tuning-library](https://github.com/surge-synthesizer/tuning-library)
(Paul Walker, MIT; see `LICENSE-tuning-library.md`). They exercise the Scala
parser and keyboard-mapping rules that Surge XT uses, so `ml::Scale` can be held
to the same frequencies.

`oracle.csv` is generated by `gen-oracle.sh` (which clones tuning-library at the
sha vendored in `external/tuning-library` and builds `gen-oracle.cpp`). `Tests/scaleTests.cpp` asserts
`ml::Scale` against it in cents. Regenerate it only when the fixtures or the
pinned sha change, and commit the result.
